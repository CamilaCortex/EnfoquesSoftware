## Proyecto del módulo

Construiremos un modelo para **predecir el precio de autos usados** usando un dataset real. A lo largo del módulo iremos mejorando el modelo paso a paso.

## Resumen

- Cómo formular un problema como regresión
- Regresión lineal: intuición y uso con scikit-learn
- Evaluar modelos con RMSE (Root Mean Squared Error)
- Framework de validación: train/validation/test
- Feature engineering: crear variables que mejoran el modelo
- Regularización: evitar overfitting
