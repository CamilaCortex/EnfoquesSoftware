## Proyecto del módulo

Construiremos un modelo para **predecir la cancelación de clientes (churn)** en una empresa de telecomunicaciones.

## Resumen

- Diferencia entre regresión y clasificación
- Análisis de importancia de variables (risk ratio, correlación, mutual information)
- One-Hot Encoding para variables categóricas
- Regresión logística: intuición y uso práctico
- Interpretación de coeficientes
